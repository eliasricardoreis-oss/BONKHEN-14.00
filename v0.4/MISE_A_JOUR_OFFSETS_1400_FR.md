# Mise à jour — offsets noyau 14.00

Al-Azif publie un fichier `1400.c` dédié au firmware 14.00 :
https://github.com/Al-Azif/ps4-exploit-kpatches/blob/main/1400.c

Ce fichier confirme l'existence de données de patch noyau spécifiques à 14.00. Il ne fournit pas à lui seul la primitive WebKit ou l'accès noyau nécessaire pour obtenir un HEN complet.

| Élément | État |
|---|---|
| Host HTML/CSS/JS | Diagnostic uniquement |
| Référence patch noyau 14.00 | Identifiée |
| Primitive WebKit 14.00 vérifiée | Non établie |
| Primitive kernel 14.00 vérifiée | Non établie |
| HEN 14.00 complet testé | Non démontré |

Ne pas exécuter de payload ni modifier la mémoire noyau à partir de cette seule référence.
